# Поиск junior QA и junior AI вакансий

Бот ищет вакансии для начинающего специалиста из Беларуси и присылает только новые совпадения. Два направления работают в одном прогоне:

1. **QA / тестирование** — junior, стажировка, опыт до 3 лет.
2. **AI / AI+QA** — junior AI, LLM, GenAI, оценка моделей, разметка данных и смежные роли.

География: вся Беларусь, включая Минск и другие города, плюс удалёнка, доступная кандидату из Беларуси.

## Источники

- **rabota.by** — официальный API `api.hh.ru` с `host=rabota.by` и `area=16` (вся страна, не только Минск). Если API отвечает 403, бот читает ту же поисковую выдачу и добирает описание из JSON-LD `JobPosting` на странице вакансии.
- **Хабр Карьера** — публичный JSON списка и JSON-LD страницы. Оставляются локации Беларуси и удалёнка, в тексте которой есть Беларусь, любая страна или работа по миру.

Вакансии белорусских компаний, опубликованные на rabota.by, уже попадают в первый источник. Отдельные career-страницы компаний не подключены: у них нет проверенного общего JSON или RSS, а разбор вёрстки каждого сайта нестабилен.

Портал без официального API в источники не добавлялся.

## Расписание

График один: **понедельник и четверг, 06:00 по Минску**.

```text
0 6 * * 1,4   Europe/Minsk
```

Сам по себе этот график ничего не отправляет. Его поднимает n8n-агент из папки `n8n/`. Локальный цикл `python -m vacancy_bot --loop` использует тот же cron, пока процесс запущен.

## Агент в n8n

Программа в `vacancy_bot/` умеет искать и фильтровать. Агент — это схема, которая сама просыпается, вызывает поиск, решает и пишет в Telegram. Схема лежит в `n8n/vacancy-agent.workflow.json`.

Внутри четыре части:

1. **Когда.** Узел «Пн и Чт 06:00». Рядом две ручные кнопки: «Тест на примерах» и «Боевой прогон сейчас».
2. **Инструмент.** Узел «Хабр Карьера» читает открытый список вакансий, без отдельного ключа. Узел «Подготовка» сразу отбрасывает Lead, Senior и Middle по карточке и оставляет вакансии Беларуси и удалёнку. Узел «Страница вакансии» открывает каждую оставшуюся страницу и берёт полный текст.
3. **Решение.** Узел «Решение» оставляет junior QA и junior AI, выкидывает senior/lead, «только РФ» и чужие профессии. Правила лежат в `n8n/decide.js`. Удалёнка без указания страны уходит с пометкой «уточните у работодателя».
4. **Куда.** Узел Telegram пишет в бота «AI вакансии». Токен в файл workflow не кладётся: его один раз сохраняют как credential в n8n.

Как проверить, не дожидаясь понедельника:

```bash
node --test n8n/decide.test.js n8n/workflow.test.js
python n8n/build_workflow.py
```

После правки `decide.js` схему пересобирают второй командой и заново загружают в n8n.

Дальше в n8n: Import from File → `n8n/vacancy-agent.workflow.json`. Открыть workflow и нажать «Тест на примерах». В узле «Решение» у каждой учебной вакансии видно `send` или `drop`. В Telegram при этом тесте сообщения нет.

Боевой прогон и расписание пишут в чат. Перед ними в n8n создайте credential с именем `AI вакансии` и вставьте токен бота из BotFather. Chat id уже стоит в узле «Настройки»: `7332843350`. Затем включите workflow переключателем Active. Пока n8n выключен или workflow не Active, утреннее сообщение не придёт.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m vacancy_bot --dry-run
```

Уведомления в Telegram:

```bash
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
python -m vacancy_bot
```

Без токена текст печатается в консоль и запоминается в `data/seen.sqlite`, чтобы следующий запуск не присылал ту же вакансию. `--dry-run` ничего не запоминает.

Повторная отправка гасится по ссылке, id вакансии и паре «компания + заголовок». Небольшая правка описания не создаёт новое уведомление.

## Фильтры

Каждая вакансия получает одну категорию: `QA`, `AI`, `AI + QA`, `ML / Data`, `AI Entry Level`. Совпадение и QA, и AI становится `AI + QA`. Смотрятся и заголовок, и описание: роль «специалист по автоматизации» с LLM/RAG в тексте попадает в AI. Упоминание QA в команде разработчиков или фраза «используем ИИ» у химика, продаж и поддержки вакансию не включают.

Приоритет у стажировки, intern, trainee, junior, junior+, entry level и опыта до 3 лет. Senior, lead, tech lead, principal, staff, head и architect в названии роли не отправляются. То же самое с явным требованием 5+ лет. Фраза вроде «работа с senior-разработчиками» у junior-вакансии её не выкидывает.

Оценка совпадения:

- 🔥 от 6 баллов — высокое совпадение
- ⭐ от 3 — стоит посмотреть
- ℹ️ от 1 — возможно подходит

В логе одного прохода: сколько вакансий найдено, сколько в каждой категории, сколько отброшено как Senior/Lead, сколько дублей и сколько отправлено.
